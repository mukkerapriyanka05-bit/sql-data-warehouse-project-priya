# Data Warehouse and Analytics Project - by Mukkera Priyanka

Welcome to my Data Warehouse and Analytics Project! This project demonstrates a complete modern data warehouse solution built using SQL Server.

**Built by Mukkera Priyanka - Aspiring Data Engineer**

### Data Architecture
This project follows Medallion Architecture - Bronze, Silver, Gold layers:
- **Bronze Layer:** Raw data from ERP and CRM CSV files
- **Silver Layer:** Data Cleaning and Standardization  
- **Gold Layer:** Business-ready Star Schema for reporting

### Project Overview
1. Data Architecture: Designing Modern Data Warehouse
2. ETL Pipelines: Extract, Transform, Load processes
3. Data Modeling: Fact and Dimension tables
4. Analytics: Creating SQL reports for business insights

### Tools Used
- SQL Server
- Git & GitHub
- Draw.io for Architecture
